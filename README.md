
# Kenya Food Insecurity Early-Warning System

## Project Overview

This project explores how Artificial Intelligence (AI) and Machine Learning (ML) can support food security monitoring in Kenya.

The project uses a trained machine learning model and an interactive Streamlit application to support food insecurity risk assessment.

## Project Objectives

- Apply machine learning to food insecurity prediction.
- Develop an interactive application for displaying model predictions.
- Demonstrate how AI can support data-driven decision-making in food security.

## Technologies Used

- Python
- Machine Learning
- Streamlit

## Project Files

- `app.py` - The Streamlit application.
- `kenya_food_insecurity_geo_model.pkl` - The trained machine learning model.
- `requirements.txt` - The Python packages required to run the application.

## How to Run the Project

### 1. Clone the repository

Download or clone this repository to your computer.

### 2. Install the dependencies

Open a terminal in the project folder and run:

```bash
pip install -r requirements.txt
```

### 3. Launch the Streamlit application

```bash
streamlit run app.py
```

The application will open in your web browser.
